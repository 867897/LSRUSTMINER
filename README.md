# LSRustMiner

LSRustMiner 是一个矿池代理程序。支持套入NUC代理。可配合LSR使用。

## 出售本套程序源代码，包含主程序，本地加密压缩客户端，远程集群端用于远程调节内置抽水，以及简易APP
